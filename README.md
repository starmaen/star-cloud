# Star Cloud — نسخ احتياطي واستعادة للأندرويد

نسخ احتياطي **انتقائي وتزايدي** إلى أكثر من مكان في الوقت نفسه، واستعادة انتقائية.

## ماذا ينسخ
- **التطبيقات**: ملفات APK كاملة (تشمل split APKs) + **بيانات التطبيق** عند توفر Root أو Shizuku بصلاحية Root.
- **الصور والملفات والمجلدات**: تصفّح حقيقي للتخزين واختيار أي مجلد/ملف، مع أزرار سريعة (الكاميرا، لقطات الشاشة، واتساب…). يدخل المجلدات الفرعية.
- **جهات الاتصال** (vCard كامل بالصور)، **الرسائل**، **سجل المكالمات**.

## أين ينسخ (وجهات متعددة)
| الوجهة | الإعداد |
|---|---|
| مجلد في الهاتف / بطاقة SD | اختيار مجلد فقط |
| Google Drive / OneDrive / Dropbox / Mega … | اختيار مجلد من منتقي النظام (يتطلب تثبيت تطبيق الخدمة) — **بلا مفاتيح ولا تسجيل دخول داخل التطبيق** |
| WebDAV / Nextcloud / NAS | رابط + مستخدم + كلمة مرور |
| Google Drive مباشر (متقدم) | يتطلب عميل OAuth من نوع Android في Google Cloud (الحزمة + بصمة SHA-1 تظهر داخل التطبيق) |

## كيف يعمل
- **تزايدي**: فهرس محلي (حجم + تاريخ التعديل) فلا يُرفع إلا الجديد أو المتغيّر.
- **تراكمي**: الملفات المحذوفة من الهاتف تبقى في النسخة (قابل للتغيير إلى «مطابقة تامة»).
- **جدولة**: يدوي / كل 6 ساعات / يومياً / أسبوعياً، مع Wi-Fi فقط والشحن فقط. يعمل كخدمة أمامية.
- **استعادة انتقائية**: اختيار الوجهة ← الهاتف (حتى لو هاتف آخر) ← ما تريد (تطبيقات مع/بدون بيانات، ملفات محددة، جهات، رسائل، مكالمات).
- أرقام التخزين **حقيقية** أو تُعرض «غير معروفة»؛ لا تقديرات.

## هيكل النسخة على الوجهة
```
StarCloud/<اسم الهاتف>/
  manifest.json
  Files/<المسار الأصلي الكامل>/…
  Apps/<package>/{base.apk, split_*.apk, data.tar.gz}
  Contacts/contacts_<تاريخ>.vcf
  Messages/{sms_<تاريخ>.json, calls_<تاريخ>.json}
```

## قيود يجب معرفتها
- بيانات التطبيقات: Root أو Shizuku **بوضع Root** فقط. Shizuku بوضع ADB لا يقرأ بيانات تطبيقات أخرى (قيد من أندرويد).
- استعادة الرسائل تتطلب جعل التطبيق «تطبيق الرسائل الافتراضي» مؤقتاً (قيد من أندرويد).
- مجلدا `Android/data` و`Android/obb` لا يمكن قراءتهما بدون Root على أندرويد 11+.
- لا يوجد تشفير للنسخ بعد (مخطط له).

## البناء
GitHub Actions يبني APK عند كل push على `main` وينشره في Release باسم `latest`.
